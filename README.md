# Khushil Ultra v2 — Sahil × Khushi Private High-Tech Couple App

## Highlights
- **High-Tech Game-Grade Graphics & Audio:** 60fps animated starfield + neon aurora backdrop, glassmorphic cards, spring animations, floating particle bursts, and procedural Web Audio sound effects.
- **Real Interactive Live Map:** Multi-layer Leaflet map (**Street Map**, **Satellite Imagery**, **Cyber Dark**) with animated glowing radar pins, GPS accuracy halos, live place names, exact Haversine distance, and Google Maps link.
- **Voice & HD Video Calling:** Built-in P2P WebRTC voice & video calls with ringtone, camera flip, mute, and live in-call heart/firework FX.
- **Stickers, GIFs, Clipboard & WhatsApp Share:** Built-in Emoji & Animated Sticker drawer, GIF search/URL picker, **📋 Paste from Clipboard**, `.webp`/`.gif` upload, and Android PWA **Share → Khushil** directly from WhatsApp.
- **Sahil Exclusive Admin Center:** Separate passcodes (`SAHIL_PASSCODE=1111`, `KHUSHI_PASSCODE=2222`). Sahil gets an exclusive **👑 Admin** tab (remote grand fireworks trigger, love takeover alerts, stealth GPS/presence/read-receipt privacy toggles, theme switcher, tab locks, message moderation) completely hidden & blocked from Khushi.
- **Grand Multi-Stage Fireworks:** 3D Heart shells, Golden Weeping Willows, Double-Ring Chrysanthemums, mid-air Crossette Crackle clusters, sky detonation flashes, and realistic sub-bass boom + whistle + crackle audio.

## Free Deploy Today (Render + Supabase Storage)
1. Push this folder to a private GitHub repo.
2. Deploy on **Render (Free Web Service)** (`npm install` / `npm start`, Node 20).
3. Add Environment Variables:
   - `SAHIL_PASSCODE` (your private Admin PIN, e.g. `1111`)
   - `KHUSHI_PASSCODE` (Khushi's separate PIN, e.g. `2222`)
   - `SUPABASE_URL` & `SUPABASE_SERVICE_KEY` (optional free cloud persistence)
   - `TENOR_API_KEY` (optional for unlimited live GIF search)
